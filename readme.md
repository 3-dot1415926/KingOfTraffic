# web游戏开发

制作一个竖屏3d驾驶游戏，主题为“公路之王”，画面主体参考一般跑酷类游戏，画面中心是3车道高速，摄像机跟随玩家控制的车辆，路上随机刷新npc车辆作为阻挡，撞到npc触发"车祸"普通结局。下方是玩家操作盘，包括方向盘控制所在车道，油门踏板以加速，刹车踏板以减速。画面左边是两个竖的填充条，一个指示刹车力量：按住刹车时填充值增长，松开刹车后缓慢回落，数值超过1612N触发"踏板断裂"特殊结局，播放车辆爆炸飞起动画；一个指示技能填充进度，随获取分数而增长。提供技能"弹射电池"，可以向左侧弹出一个电池，击中npc车辆触发npc爆炸并加分；技能"主动弹跳"，允许玩家车辆跳起，一段时间后落回地面；技能"喷气起飞"，让玩家车辆在空中喷气飞行一段时间后落下。道路上刷新特殊车辆：油罐车，碰撞后发生范围爆炸；平板挂车，挂车的上层板放下形成斜坡，玩家可以在此车辆后方加速以触发飞坡，获得更多分数。npc有小概率主动变道、加速或减速等特殊动作，且变道时不一定会打转向灯，玩家提供一个"鸣笛"按钮，点击后增加前方一台npc车辆的特殊动作概率。当玩家车辆从前方被后方的npc撞击，触发"我追他尾"特殊结局。画面上方展示当前的分数值。屏幕中还需要显示速度表和油量表，玩家车速越高每秒的加分越多，当油量表为0时触发"燃料耗尽"普通结局。玩家刚启动游戏时在画面顶层显示一个欢迎窗口，显示游戏标题和介绍，介绍例如“看看你能坚持多久，成为公路之王？”，背景展示公路上的玩家车辆场景，点击开始按钮后正式开始游戏。触发任意一个结局若干秒后弹出结算窗口。
